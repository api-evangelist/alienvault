# AlienVault OTX

> AlienVault's Open Threat Exchange (OTX) is one of the largest open threat-intelligence
> communities. The OTX DirectConnect API provides programmatic access to threat "pulses"
> (curated indicator-of-compromise collections), indicator detail lookups (IPv4/IPv6,
> domain, hostname, URL, file hash, CVE), pulse/user search, and indicator submission.
> Authentication is via an X-OTX-API-KEY header. Now operated under the LevelBlue brand.

## APIs
- [OTX DirectConnect API](https://otx.alienvault.com/api): pulses, indicators, users, search. Base URL https://otx.alienvault.com/api/v1
